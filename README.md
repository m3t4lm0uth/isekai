# Isekai

**Isekai** is a mod that implements isekai reincarnation mechanics in Minecraft. 

## Purpose
- The player begins in a hardcore environment, and is shocked to find that, upon death, they have been transported to another world instead of being booted to the title screen.
- After X requirements have been met in this new world, the player is given the option to return to their original world - with a trophy.

## Additional notes

This mod is currently in development, with the intention for it to be compatible with servers as well as single player worlds. It will eventually work as a standalone mod, as well as be compatible with pre-existing modpacks / worlds.
